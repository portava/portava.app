Read this before reviewing. This page is rendered by react-native-web, not by React Native on Android or iOS. Layout, spacing and type scale come from the real component code, but shadow rendering, font metrics and text measurement differ from a device. It is a fidelity-limited proxy, sound for judging density, rhythm and whitespace — the two questions being asked — and it is not evidence about pixel-exact device appearance. Media wells show the real component's “No preview” placeholder at the real aspect ratio; no image bytes are fetched, so every card is lighter here than it will be with a photograph in it.

Two further substitutions, both visible above: icons are drawn as neutral 16 px squares (the harness cannot render lucide glyphs; real Wall icons are 14–26 px), and the page requests Roboto, the Android platform font the app actually inherits. If Roboto did not load, line wrapping here will not match the device — check that this sentence is set in Roboto before judging any width.
