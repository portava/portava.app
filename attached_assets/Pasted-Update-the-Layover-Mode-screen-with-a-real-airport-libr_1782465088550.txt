3. Airport search behavior
Update the Airport input on Layover Mode:
- Search by IATA code, ICAO code, airport name, city, or country.
- Show autocomplete results while typing.
- Prefer exact IATA matches when user types 3 letters.
- Show result labels like: “TPE — Taiwan Taoyuan International Airport, Taipei, Taiwan.”
- Selecting an airport fills the airport field and stores airport metadata.
- If no match is found, show a helpful empty state instead of silently failing.

4. GPS/location integration
When an airport is selected, link it to the GPS system:
- Use airport latitude/longitude as the origin point.
- Calculate nearby activities based on the airport location.
- Use the existing location/Discovery/map services where possible.
- Support user current GPS location when permission is granted.
- If user is physically near the selected airport, show “You are near this airport.”
- If location permission is denied, still use selected airport coordinates.
- Do not require live GPS for airport-based recommendations.

5. Layover Mode functionality
Make the screen fully functional:
- Airport search works.
- Time window fields work.
- Domestic / International selection affects recommendations.
- Immigration required toggle affects whether leaving airport is safe.
- Checked bags toggle affects time needed.
- Lounge access toggle can suggest lounge/airport-only options.
- Want to leave airport toggle determines whether outside-airport activities are allowed.
- Comfort level changes recommendation strictness:
  - Safe only
  - Balanced
  - Adventurous
- Results should update based on airport, layover time, flight type, toggles, and comfort level.

6. Recommendation logic
Use safe layover timing rules:
- Calculate total layover hours from arrival/departure window.
- Estimate minimum buffer time:
  - domestic airport-only
  - domestic leaving airport
  - international airport-only
  - international leaving airport
  - immigration required
  - checked bags
  - return-to-airport buffer
- If time is too short, recommend airport-only options.
- If time is enough, recommend nearby activities within a safe travel radius.
- Show clear reasons like:
  - “Airport-only recommended because immigration and checked bags reduce your safe free time.”
  - “You have enough time for nearby food or a short landmark visit.”
- Do not recommend leaving the airport when the inputs make it unsafe.
