Build the Safe Return system and temporary trusted-circle live sharing for Travel Buddy.

Stay focused only on Safe Return. Do not expand into Passport rewards, airport mode, Compass AI rewards, Trust Score formulas, or broader GPS discovery in this pass.

Build this on top of the shared Location Intelligence Layer and Plans GPS/geofence system.

CORE PRINCIPLE

Safe Return is private-by-default safety infrastructure.

It helps users confirm they made it back safely after plans, nightlife, solo activities, first-time meetups, or travel activities in a new city.

Exact GPS must never be public.

Safe Return must not become always-on tracking.

Trusted Circle alerts and live sharing must only happen if the user explicitly opted in.

The app must not automatically call law enforcement.

The app can present emergency options, but the user or trusted contact chooses what to do.

SAFE RETURN TRIGGERS

Safe Return should be suggested when:

- Plan category is nightlife
- Plan is late-night
- User is attending solo
- User is meeting someone for the first time
- User is in a new city
- User is far from their hotel/stay area, if known
- Plan location has caution flags
- User manually enables Safe Return

Safe Return should also be manually available from:

- Plan detail screen
- Active plan screen
- Trip Crew screen
- Safety tab/settings
- User profile safety shortcut if applicable

SAFE RETURN ESCALATION LEVELS

Create clear escalation levels:

Level 0 — Reminder only
- App reminds the user to confirm they are safe.
- No trusted contacts are notified.

Level 1 — Trusted Circle check-in
- If user misses the check-in, selected trusted contacts receive an alert.
- No exact location is shared unless separately enabled.

Level 2 — Temporary live location share
- If user misses the check-in and opted in, selected trusted contacts can view temporary live location.
- Live sharing must expire automatically.

Level 3 — Emergency help prompt
- App shows emergency options:
  - Call local emergency number
  - Message Trusted Circle
  - Share current location
  - Open rideshare/maps
  - Contact host
  - Contact Trip Crew
- The app must not automatically call police/law enforcement.

The setup screen should include:

- Toggle: share temporary live location if I miss check-in

- Emergency note/message field
- Privacy explanation
- Start Safe Return button

Default settings:
- Safe Return suggested, not forced.
- Default escalation = Level 0 reminder only.
- Trusted Circle alerts off unless user enables them.
- Live sharing off unless user enables it.
- Timer default can be 30 minutes or until plan ends depending on plan context.

MISSED CHECK-IN FLOW

When the timer expires or the check-in is missed, show:

“We couldn’t confirm you’re safe.”

Options:

- I’m Safe
- Extend 15 minutes
- Alert my Trusted Circle
- Share live location
- Emergency Help

If the user selected Level 0:
- Only notify the user.

If the user selected Level 1:
- Notify selected Trusted Circle contacts after missed check-in.

If the user selected Level 2:
- Notify selected Trusted Circle contacts and start temporary live sharing only if previously enabled.

If the user selected Level 3:
- Show emergency help prompt. Do not auto-call emergency services.

TRUSTED CIRCLE ALERTS

Trusted Circle contacts should receive a calm alert.

Alert should include:

- User display name
- Plan title
- Last Safe Return status
- Last known approximate area
- Missed check-in time
- Optional emergency note
- Live location link/view only if user enabled it
- Buttons/actions:
  - Message user
  - Call user, if phone contact exists
  - View shared location, if allowed
  - Mark contacted/checking in, if applicable

Do not include exact location unless live sharing was explicitly enabled.

TEMPORARY LIVE LOCATION SHARING

Implement temporary live sharing for Safe Return.

Rules:

- Must be opt-in.
- Must have expiration.
- Can be shared only with selected Trusted Circle contacts.
- Can be stopped by user anytime.
- Can be started manually by user anytime.
- Can be started automatically after missed check-in only if user pre-approved it.
- Never appears on public Pulse, Discovery, Passport, or public plan surfaces.
- Show approximate area if exact sharing is not enabled.
- Show expiration countdown to both user and trusted contact where applicable.

Live sharing durations:

- 15 minutes
- 30 minutes
- 1 hour
- Until Safe Return closes
