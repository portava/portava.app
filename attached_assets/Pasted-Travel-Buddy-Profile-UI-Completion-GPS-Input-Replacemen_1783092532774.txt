Scope B — GPS + Assisted Location Input Replacement

1. Remove manual coordinate entry
   Search for:
   - latitude
   - longitude
   - lat
   - lng
   - coordinates
   - GPS coordinates
   - exact location
   - manual coordinate TextInput
   - numeric keyboard for location fields

   Replace any user-facing coordinate entry with:
   - “Use my current location”
   - location permission request
   - GPS capture
   - reverse-geocoded label if available
   - privacy explanation
   - denied/unavailable fallback

2. Profile home city/country
   Replace manual home city/country typing with assisted location input:
   - City search if available
   - Country derived from city selection
   - “Use current location” option to prefill city/country
   - User can still select a different city from suggestions
   - Do not store precise GPS on profile
   - Profile displays city/country only if privacy allows

3. Reusable GPS/location components
   Create or reuse:
   - `GpsLocationCapture`
   - `CitySearchField`
   - `LocationSearchField`
   - `LocationPrivacyNotice`
   - `LocationDisplay`

   Minimum behavior:
   - request permission only after tap
   - handle granted/denied/unavailable/timeout
   - return `{ latitude, longitude, city, region, country, label, accuracy }`
   - do not expose raw coordinates to public UI
   - show privacy-safe label

4. Assisted city/place results
   Inspect existing providers:
   - expo-location
   - discovery/place APIs
   - OSM/Nominatim route
   - Foursquare/Google Places route
   - saved/recent/popular locations

   Prefer existing backend/provider code.
   Do not expose secret API keys on mobile.
   If no backend city search exists, use the smallest safe local/prefilled library or existing app data as initial suggestions.

5. GPS-required flows
   If a flow needs verified location/stamp/location credit:
   - GPS is required.
   - Do not allow typed coordinates.
   - If permission denied, show “GPS is required for this feature.”
   - Do not fake stamp/location success.

6. Public location privacy
   Ensure:
   - public profile shows city/country only, never GPS
   - posts/memories show privacy-safe labels
   - delayed posting hides real-time precise location
   - Safe Return live location is only for trusted contacts
   - public places may show coordinates, but user live GPS must stay private
