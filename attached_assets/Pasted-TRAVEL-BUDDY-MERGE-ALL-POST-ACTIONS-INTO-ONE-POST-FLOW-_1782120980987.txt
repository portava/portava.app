TRAVEL BUDDY — MERGE ALL POST ACTIONS INTO ONE POST FLOW

Problem:
The mobile Pulse screen still has duplicated creation actions:
- Header “Post” button
- Bottom Post/Postcard floating button
- Post action sheet with multiple separate options

This is cluttered. Merge everything into one clean Post flow.

Mission:
There should be ONE visible Post button on mobile. When the user taps Post, they choose the occasion/post type inside the composer flow.

Do not delete any post types.
Do not break existing post APIs.
Do not break Pulse.
Do not break Passport/Postcards.
Do not break hidden gem sharing.
Do not break food spot sharing.
Do not break question/update posts.
Do not break desktop unless desktop has the same duplicated problem.

============================================================
DESIRED USER FLOW
============================================================

Mobile Pulse header:

Cebu Pulse                         [Filter icon] [Post]

Bottom nav:
Pulse / Explore / Trips / Passport

No floating Post/Postcard button at the bottom.

When user taps Post:

Step 1:
Open a unified Post composer.

At the top of the composer, ask:

“What are you sharing?”

Options:
- Post Update
- Ask Question
- Share a Moment
- Share Postcard
- Share Hidden Gem
- Share Food Spot

The user selects the occasion/type.

Step 2:
Composer adapts based on selected type.

Post Update:
- Text required
- Photo optional

Ask Question:
- Question/text required
- Photo optional

Share a Moment:
- Text required
- Photo optional or recommended, but not blocking unless existing product rules require it

Share Postcard:
- Photo recommended
- Caption optional or required based on existing postcard rules
- Location optional/auto-filled if available

Share Hidden Gem:
- Place/location required
- Description required
- Photo optional or recommended
- Category optional if already exists

Share Food Spot:
- Place/location required
- Description or recommendation required
- Photo optional or recommended
- Cuisine/type optional if already exists

Important:
Post Update and Ask Question do NOT require a photo. Photo is optional for both.
