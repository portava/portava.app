Build Airport / Layover Mode for Travel Buddy.

Build this after the full platform wiring pass so Airport Mode can reuse GPS, Discovery, City Pulse, Plans, Safe Return, Trip Crew, Compass AI, Telegraph, Passport, Hidden Gems, and trusted location systems.

Stay focused on Airport / Layover Mode only. Do not expand into flight booking, airline booking, hotel booking, or paid travel marketplace in this pass unless only creating backend seams.

CORE PRINCIPLE

Airport / Layover Mode helps travelers decide what they can safely do during a layover, airport wait, arrival window, or short stopover.

It should recommend time-safe activities, food, hotels, areas, meetups, hidden gems, and routes based on:
- Airport location
- User’s available time
- Immigration/customs risk
- Distance from airport
- Return buffer
- Traffic/time of day
- User vibe/preferences
- Safety
- Trusted plans/people nearby

Airport Mode should protect the user from risky recommendations that could make them miss a flight.

LAYOVER SAFETY ENGINE

Create a Layover Safety Engine that calculates whether an activity is safe based on available time.

It should consider:

- Time until boarding
- Airport return buffer
- Immigration/customs time
- Security re-entry time
- Travel time to/from activity
- Traffic risk
- Time of day
- Distance from airport
- User’s luggage situation
- Whether the user is in a new country
- Whether the user has local transport confidence
- Whether the activity is indoors/outdoors
- Whether activity is verified
- Whether user is alone or with Trip Crew

Recommendation categories:

1. Safe
- Low chance of missing flight
- Close to airport or inside airport
- Comfortable time buffer

2. Possible but risky
- Can work if user moves fast
- Requires strict return time
- Show warning

3. Not recommended
- Too far, too little time, uncertain immigration/security, heavy traffic, or late-night risk

4. Airport-only
- User should stay inside airport

Do not recommend risky activities as primary options.

TIME BUFFER RULES

Create configurable buffer defaults:

Domestic:
- Minimum airport return buffer: 60–90 minutes

International:
- Minimum airport return buffer: 2–3 hours

If immigration/customs required:
- Add extra buffer

If checked bags / recheck required:
- Add extra buffer

If traffic risk high:
- Add extra buffer

If late-night / unfamiliar city:
- Add caution

Compass AI should say things like:
- “This is safe with your time window.”
- “This is possible, but your return buffer is tight.”
- “I would not leave the airport with this layover.”
- “Stay within 15–20 minutes of the airport.”
- “Use rideshare, not walking, for this one.”
