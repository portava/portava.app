Build Passport Stamps and verified location memories for Travel Buddy.

Build this on top of the shared Location Intelligence Layer, Plans geofencing, Safe Return, Trip Crew map, Discovery GPS, City Pulse GPS, and Compass AI Location Intelligence.

Stay focused on Passport Stamps, verified memories, location-based identity, and safe contribution history. Do not expand into full rewards marketplace, paid perks, or monetization in this pass unless only creating backend seams.

CORE PRINCIPLE

Passport Stamps should prove meaningful travel activity without storing or exposing exact private location history.

Users should earn city, neighborhood, plan, hidden gem, and activity stamps from verified presence, check-ins, and completed travel actions.

Exact GPS must never be public.

Passport should show memories and verified presence, not raw coordinates or full movement history.

PASSPORT STAMP TYPES

Create stamp types:

1. Country Stamp
- User verified presence in a country.

2. City Stamp
- User verified presence in a city.

3. Neighborhood Stamp
- User verified presence in a neighborhood or zone.

4. Plan Stamp
- User attended or checked into a plan.

5. Host Stamp
- User hosted a verified plan.

6. Hidden Gem Stamp
- User verified or visited a hidden gem.

7. City Pulse Contributor Stamp
- User posted useful local content from a city/neighborhood.

8. Trip Crew Stamp
- User participated in a trip crew activity.

9. Safe Traveler Stamp
- User completed Safe Return after a plan.

10. Explorer Category Stamp
- Food, nightlife, beach, culture, shopping, landmarks, nature, events.

11. Verified Venue Stamp
- User visited or checked into a verified venue.

12. First-Time Stamp
- First city, first country, first hosted plan, first hidden gem, first Trip Crew activity.

STAMP PRIVACY RULES

Public Passport should never show exact coordinates.

Stamp visibility options:
- Public
- Friends / Trusted Circle
- Trip Crew only
- Private

Default:
- Country/city stamps can be public.
- Neighborhood stamps default to friends/trusted circle or private depending on user settings.
- Plan stamps follow plan privacy.
- Safe Return stamps default private.
- Hidden Gem stamps can hide exact place if gem is sensitive.
- Hotel/home/stay-area stamps are never public.

Passport should use safe labels:
- “Tokyo, Japan”
- “Makati nightlife”
- “Mactan beach day”
- “Da Nang hidden gem”
- “Cebu food explorer”
- “Safe Return completed”

Do not show:
- Exact latitude/longitude
- Hotel address
- Home/private stay location
- Private meetup address
- Hidden plan coordinates
- Another user’s private location
