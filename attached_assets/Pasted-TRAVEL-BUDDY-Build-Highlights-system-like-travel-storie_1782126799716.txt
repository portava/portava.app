TRAVEL BUDDY — Build Highlights system like travel stories + 10-second video Postcards.

Mission:
Build a Travel Buddy Highlight system similar to Instagram Stories, but designed around Passport, Pulse, Telegraph, Trips, and travel discovery.

Users can post temporary pictures or short videos, choose how long they stay visible, see who viewed them, see who liked them, and receive replies through Telegraph. Active highlights should appear as a ring around the user’s display picture. Also allow users to upload or record short 10-second videos for Postcards.

Do not break existing Post, Passport, Pulse, Telegraph, Trips, Discovery, profile photo upload, or like/comment/share systems.

============================================================
CORE HIGHLIGHT BEHAVIOR
============================================================

Users can create a Highlight with:
- photo
- video up to 10 seconds
- caption optional
- location optional
- visibility setting
- expiration duration

Media source:
- upload from gallery
- take live photo from camera
- record live video from camera

Expiration options:
- 3 hours
- 6 hours
- 12 hours
- 24 hours default
- 48 hours
- until trip window ends if available
- until I leave this city if location/session system supports it
- custom if simple to support

Active highlights are visible until expires_at.

Expired highlights should not show publicly.

Show ring in:

============================================================
PRIVACY / VISIBILITY
============================================================

Visibility options:
- public
- travelers_nearby
- trip_only
- circle_only
- followers_or_connections if existing
- private

Default:
travelers_nearby

Rules:
- public: authenticated users who can see public content may view/like/reply/share
- travelers_nearby: users in same city/area can view if location system supports it
- trip_only: accepted trip members only
- circle_only: accepted trusted circle members only
- private: owner only
- deleted/expired/reported-restricted: hidden

Add shared permission helper:
canViewHighlight(user, highlight)
canEngageWithHighlight(user, highlight, action)

============================================================
API
============================================================

Add endpoints:

POST /api/highlights
- create highlight
- authenticated
- accepts media upload or media reference
- validates media type
- validates video duration <= 10 seconds
- validates expiration duration
- saves highlight
- returns highlight

GET /api/highlights/active
- returns active highlights visible to current user
- supports city/trip/user filters

GET /api/users/:userId/highlights
- returns active highlights for a user if viewer has permission

POST /api/highlights/:id/view
- marks current user viewed
- idempotent

POST /api/highlights/:id/like
- like
- returns likedByMe and likeCount

DELETE /api/highlights/:id/like
- unlike

GET /api/highlights/:id/viewers
- creator/admin only
- returns viewer list and liked status

POST /api/highlights/:id/reply
- creates Telegraph reply/share intent

DELETE /api/highlights/:id
- owner/admin only
- soft delete

POST /api/highlights/:id/report
- report highlight
