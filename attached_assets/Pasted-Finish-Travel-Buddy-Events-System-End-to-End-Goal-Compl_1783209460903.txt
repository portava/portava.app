Finish Travel Buddy Events System End-to-End

Goal:
Complete the Events feature so users can create, draft, publish, discover, search, join/request, manage, attend, review, and interact with events using real backend/database truth.

Events must connect cleanly to:
- Discovery
- Global Search
- Pulse
- Passport
- Trips
- Telegraph
- Notifications
- Location/GPS
- Hashtags
- Postcards/media
- Trust Score
- Safety
- Admin moderation

Core rules:
- Events are real backend/database objects.
- No fake local event data.
- No mock production events.
- Event join/request/attending/maybe/save states must use one backend truth everywhere.
- Public events can be discovered.
- Private/invite-only/trip-only/circle-only events only appear to users with access.
- Age-restricted, verified-only, or trust-gated events only appear/action correctly for eligible users.
- Blocked users and users who blocked the viewer must be respected.
- Events should support location, time, host, cohosts, attendees, tags, comments/Q&A, media, reviews, check-ins, reminders, and Telegraph group chat where applicable.
- Do not rebuild unrelated systems.
- Audit first, then patch only confirmed gaps.
