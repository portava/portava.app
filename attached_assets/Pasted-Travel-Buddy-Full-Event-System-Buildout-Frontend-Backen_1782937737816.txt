Travel Buddy — Full Event System Buildout, Frontend + Backend

You are building the full Events system for Travel Buddy.

Important product direction:
Travel Buddy is a social media app for travelers. Events are core social objects that help travelers find things to do, meet people safely, create plans, join activities, post updates, message attendees, and connect events to Trips, Pulse, Discovery, Passport/Profile, Telegraph, Circles, Safe Return, Trust Score, and Rent a Buddy.

Do not delete existing working systems.
Do not fake events, users, places, RSVPs, reviews, ratings, comments, tickets, payments, or activity.
Inspect what exists first.
Patch/build only after inventory.
Preserve auth/session behavior.
Use real backend data.
Everything must be cohesive with Pulse, Discovery, Trips, Passport/Profile, Telegraph, Rent a Buddy, Trust Score, verification, delayed posting, privacy, safety, and city/location-aware discovery.

Primary goal:
Build a complete Event system where users can:
- create events
- save draft events
- resume/discard drafts
- browse events nearby or by destination
- join/request to join events
- RSVP going/maybe
- join waitlists when full
- set event privacy and capacity
- set age limits and trust/verification requirements
- invite friends/trip crew/circle members
- add cohosts
- attach real places/venues
- chat with attendees through Telegraph
- post event updates
- save events
- add events to trips
- connect events to circles
- report/block unsafe events or users
- receive reminders/notifications
- earn stamps/badges from real event participation
- moderate/admin-review events when needed
- support future recurring events, tickets, and calendar view without faking them
