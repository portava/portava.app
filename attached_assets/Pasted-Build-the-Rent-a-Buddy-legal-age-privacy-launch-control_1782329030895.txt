Build the Rent a Buddy legal, age, privacy, launch-control, and compliance hardening layer.

Goal:
Harden Rent a Buddy before launch by adding age rules, ID/verification requirements, city/country/category rollout controls, privacy protections, legal disclaimers, delayed posting integration, tagging consent, transport boundaries, tour-guide wording, support windows, and MVP launch restrictions.

Feature flag:
Use RENT_BUDDY_ENABLED.
If disabled, hide all traveler/Buddy entry points and return honest feature-disabled responses.

Age rules:
Rent a Buddy is 18+ only.

Rules:
- Travelers must be 18+ to book Rent a Buddy.
- Buddies must be 18+ to apply.
- Nightlife Buddy requires 21+ where alcohol/nightclubs are involved or where local rules require it.
- No minors can book, offer, appear as Buddies, or join a Rent a Buddy group booking.
- If age is missing or unverified, block booking/application until verified.
- Admin can configure stricter age rules by country/category.

Add age policy copy:
“Rent a Buddy is only available to adults 18+. Nightlife bookings may require users to be 21+ depending on location and venue rules.”

Verification requirements:
Require verification before booking or Buddy approval.

Traveler minimum:
- Phone verified
- Email verified if available
- Age confirmed
- ID verification required for first booking, nightlife booking, high-value booking, or admin-configured risk rules

Buddy minimum:
- Phone verified
- Email verified if available
- Age confirmed
- ID verified
- Selfie match if supported
- Admin reviewed
- Policy/training checklist completed

Nightlife Buddy:
- ID verified
- Age verified
- Manual admin approval
- Public meetup required
- Safe Return recommended or required by admin setting
- Higher deposit/full in-app payment if risk rules require it

If existing verification systems are not fully built, add placeholder fields and honest gates. Do not fake verification.

Legal and policy disclaimers:
Add legal/policy copy to:
- Rent a Buddy landing page

- Terms/legal page if one exists

Required disclaimer:
“Rent a Buddy connects travelers with verified local Buddies for social exploration, city guidance, language help, shopping help, arrival support, content help, and local navigation. Rent a Buddy is not a dating, escort, adult, romantic, sexual, transportation, emergency, medical, security, or licensed tour-guide service. Users must follow local laws and Travel Buddy safety rules.”

Adult-service disclaimer:
“Requests or offers involving dating, escorting, romantic companionship, sexual services, private adult activity, illegal activity, drugs, harassment, or off-app payment are not allowed and may result in account review, suspension, removal, and Trust Score penalties.”

Emergency disclaimer:
“In an emergency, contact local emergency services immediately. Travel Buddy safety tools are not a replacement for police, medical, emergency, or professional security services.”

Transportation disclaimer:
“Buddies may help with navigation or coordinating third-party transportation, but Rent a Buddy is not a rideshare, taxi, chauffeur, airport transfer, or transportation service. Buddies should not be presented as drivers unless a future verified transport feature is legally supported.”

Privacy protections:
Because Rent a Buddy uses location, identity, messages, payments, and reviews, add strict privacy controls.

Before payment/deposit:
Buddy can see:
- Traveler first name/display name
- Approximate age range if needed
- Trust Score
- Languages
- Booking request details
- Public meetup area/neighborhood
- Safety preferences needed for booking

Buddy should not see:
- Exact hotel room
- Exact private address
- Emergency contact
- Full legal name
- ID documents
- Active precise location before booking starts

Traveler can see:
- Buddy display profile
- Verification badges
- Buddy categories
- Approximate city/area
- Reviews
- Rates
- Safety badges

Traveler should not see:
- Buddy legal name
- ID documents
- private address
- personal phone/email unless both users choose to share outside platform, which should be discouraged

Delayed posting integration:
Connect Rent a Buddy with Delayed Location Posting.

Rules:
If a user creates a geotagged post during an active Rent a Buddy booking:
- Default to “Post after I leave.”
- Hide exact location by default.
- Do not expose live meetup location.
- Do not tag the Buddy publicly without Buddy approval.
- Do not tag the traveler publicly without traveler approval.
- If Safe Return is active, hold public posting until Safe Return ends or safety rules allow publish.
- For nightlife, hotel, private lodging, or low-crowd venues, default to city/neighborhood only.

Add UI copy:
“Posts made during Rent a Buddy bookings are delayed by default to protect everyone’s real-time location.”

Tagging consent:
Add mutual tagging consent for Rent a Buddy posts, photos, videos, and reviews.

Rules:
- Traveler cannot publicly tag Buddy in a post without Buddy approval.
- Buddy cannot publicly tag traveler without traveler approval.
- Either user can hide the tag from their profile.
- Either user can request removal of a tag.
- If a booking is disputed or safety-flagged, hold public tags until resolved.
- If user is blocked/suspended, remove or hide pending tags.

rent_buddy_tag_consents:
- id
- booking_id
- post_id nullable
- requester_user_id
- tagged_user_id
- consent_status: pending, approved, declined, removed
- requested_at
- responded_at
- removed_at

Nightlife rules:
Add stricter controls for Nightlife Buddy.

Rules:
- Manual category approval required.
- Public meetup required.
- Buddy cannot bring unapproved guests.
- Traveler cannot bring unapproved guests beyond booking group.
- Safe Return recommended or admin-required.
- Higher deposit or full in-app payment can be required.
- Route changes require approval.
- Venue changes require approval.
- Late-night end should trigger Safe Return prompt.
- Repeated nightlife complaints trigger review even if Trust Score is high.

Nightlife prohibited behavior:
- Pressuring user to drink
- Taking intoxicated user to unsafe/private location
- Abandoning user mid-booking
- Venue kickback scams
- Surprise cover/table charges without approval
- Private after-party pressure
- Adult/romantic/sexual pressure
- Drug-related requests

Venue scam prevention:
Track repeated complaints involving:
- Overpriced bars
- Forced purchases
- Surprise charges
- Buddy repeatedly routing users to same suspicious venue
- Buddy refusing to leave venue
- Traveler reporting pressure to buy bottles/items
- Venue changes without approval

Create policy/safety events for suspected venue scam patterns.
