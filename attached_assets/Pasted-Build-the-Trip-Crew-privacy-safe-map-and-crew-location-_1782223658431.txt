Build the Trip Crew privacy-safe map and crew location coordination system for Travel Buddy.

Build this on top of the shared Location Intelligence Layer, Plans geofencing, and Safe Return system.

Stay focused on Trip Crew coordination only. Do not expand into Passport rewards, airport mode, Compass AI, or broader Discovery in this pass.

Core principle:
Trip Crew location should help accepted members coordinate safely without exposing exact location by default.

Exact GPS must never be public.
Exact crew pins must never be shown by default.
Crew members should see privacy-safe status, approximate area, arrival state, and optional temporary live share only when explicitly enabled.

TRIP CREW MAP FEATURES

Create a Trip Crew map or coordination screen showing:
- Crew members
- Plan locations
- Accepted trip activities
- Nearby/arrived/on-the-way statuses
- Safe Return active status
- Optional live sharing status
- Approximate group areas
- Venue or meetup markers where allowed

Crew member status options:
- Not shared
- City only
- Same neighborhood
- Nearby
- On the way
- Arrived
- Checked in
- Safe Return active
- Confirmed safe
- Needs check-in
- Live sharing active

Do not show exact coordinates unless the user has enabled live sharing for that crew.

LOCATION PRIVACY LEVELS

Support crew location visibility levels:
1. Hidden
2. City only
3. Neighborhood
4. Nearby status
5. Arrived/check-in status
6. Temporary live share

Default:
- City/neighborhood or status only
- No exact pin
- No live sharing unless user opts in

TEMPORARY LIVE SHARE

Crew members can choose:
- Share exact location for 15 minutes
- Share exact location for 30 minutes
- Share exact location for 1 hour
- Share until plan ends
- Stop sharing anytime

Live sharing must expire automatically.

Only accepted Trip Crew members selected by the user can view live sharing.

Removed users lose access immediately.

APPROXIMATE MAP DESIGN

Use privacy-safe map visuals:
- Area bubbles
- Venue markers
- Plan markers
- “Nearby” rings
- Group density indicators
- Arrival status labels

Avoid exact person pins unless live share is active.

Examples:
- “3 crew members near the venue”
- “Andre is nearby”
- “Maya arrived”
- “2 crew members still on the way”
- “Safe Return active for 1 member”

PLAN + CHECK-IN INTEGRATION

Connect Trip Crew map to Plans:
- Show accepted plan meetup points only to accepted members.
- Hide private exact locations from pending/rejected/removed users.
- Show check-in status from plan geofencing.
- Show host arrived status if allowed.
- Show number of crew members checked in.
- Let users open plan details from the crew map.

SAFE RETURN INTEGRATION

Connect Safe Return:
- Show “Safe Return active” status only to allowed crew/trusted contacts.
- Do not reveal Safe Return location unless user enabled live sharing.
- Show “confirmed safe” when user completes Safe Return.
- Show “needs check-in” only according to Safe Return privacy settings.
- Do not notify full crew unless user enabled crew notification.

GHOST MODE

Add Ghost Mode support:
- Hide user from crew map
- Stop live sharing
- Hide nearby status
- Keep manual check-in available
- Keep Safe Return available
- Show user as “Location hidden”

Ghost Mode should not remove the user from the trip or plan.
