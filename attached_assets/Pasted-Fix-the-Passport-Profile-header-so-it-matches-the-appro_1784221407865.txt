Fix the Passport/Profile header so it matches the approved Portava Passport design exactly.

GOAL

The Passport header should look like a real modern digital passport identity page, using the approved Portava visual style.

The current Passport header does not match the approved design. Audit the existing Passport/Profile header implementation first, then update the existing components rather than rebuilding the entire screen.

HEADER LAYOUT

The Passport page should have this structure at the top:

1. Cover / Passport Header Area
2. Profile photo
3. Name and verification
4. Username / handle
5. Location and basic identity information
6. Compact Trust Score inside the Identity Information area
7. Followers / Following / Trips or existing approved stats
8. Passport stamps preview
9. Existing Passport tabs/content below

The overall layout must feel like a digital passport, not a generic social-media profile.

COVER / TOP HEADER

Keep the existing Portava color scheme.

The top header/cover should stretch fully across the available screen width.

Remove unnecessary gaps that make the header look detached from the screen edges.

Respect the safe area at the top.

The visual hierarchy should feel premium, clean, and travel-focused.

Do not create excessive vertical height.

The header should be compact enough that users can still see Passport content below without excessive scrolling.

PROFILE PHOTO

Display the user's main profile photo prominently in the Passport header.

The photo should visually overlap or integrate with the cover/header section where appropriate.

Maintain a clean circular avatar unless the approved existing design uses another shape.

Add an owner-only edit control for changing the profile/display photo.

The edit button should have at least a 44x44 usable touch target.

Do not send the user directly into Highlight creation when tapping the profile photo camera/edit control.

For the profile owner, tapping the camera/edit action should open a menu with appropriate choices such as:

- Change display photo
- Add or create Highlight

Do not show owner-only edit controls when viewing another user's public Passport.

COVER PHOTO EDITING

Add a visible but subtle owner-only camera/edit button on the Passport cover image.

Tapping it should allow the owner to change the cover photo.

Do not show this button on public views of another user's Passport.

NAME AND VERIFICATION

Display the user's name prominently.

The verified status/stamp should appear next to the name or in the approved Identity section.

Only display the verified stamp when the backend verification status confirms the user is actually verified.

Do not hard-code verification.

Use the existing verification truth from the backend/database.

USERNAME / HANDLE

Display the user's handle directly below or near the name.

The app uses the invariant:

username = handle

The displayed value should be normalized to lowercase.

Do not introduce two separate visible username/handle identities.

- Country
