ADDENDUM — Full Passport Stamp Artwork & Design System

Add a complete stamp artwork/design function to the Passport Stamps system.

Goal:
Passport Stamps should feel collectible, premium, travel-themed, and consistent across the app. They should not look like random badges. Each stamp needs a clear visual identity, rarity treatment, category style, and reusable artwork rules.

Do not use copyrighted logos, airline logos, country seals, government passport marks, or protected brand artwork.
Do not fake official immigration/passport stamps.
Do not imply government-issued travel proof.
These are Travel Buddy in-app collectible stamps only.

PHASE 2 — Design language rules

All stamps must follow a consistent Travel Buddy visual system.

Base rules:
- stamp name readable at small size
- icon clear at 32px
- category recognizable
- rarity visible but not overwhelming
- works in light and dark mode
- works in grid, strip, modal, share card, and notification
- has accessible label
- no clutter
- no tiny unreadable text
- no real government/passport seal imitation
- no copyrighted brand marks
- no fake immigration authority marks

Visual tone:
- premium
- fun
- collectible
- social travel
- passport-inspired
- modern, not childish
- slightly textured like travel stamps
- clean enough for mobile

PHASE 3 — Stamp category design themes

Create reusable artwork themes by category.

Location stamps:
- visual style: passport stamp / city mark
- icons: city skyline, map pin, landmark silhouette, compass
- patterns: subtle map, passport paper
- colors: city/country themed but not flag-dependent unless generic
- shape: oval or passport_stamp_rectangle

Trip stamps:
- visual style: luggage tag / boarding pass
- icons: suitcase, route line, plane, backpack, calendar
- patterns: boarding_pass, compass_grid
- shape: rounded_square or luggage_tag

Event stamps:
- visual style: ticket stub / event wristband
- icons: people, music, fork, beach, camera, sports
- patterns: stars, wave, palm, none
- shape: ticket_stub or circle

Social/community stamps:
- visual style: postcard mark / social badge
- icons: postcard, chat bubble, camera, heart, group
- patterns: paper_grain, subtle_map
- shape: postcard_mark or rounded_square

Safety/trust stamps:
- visual style: shield / verified badge
- icons: shield, check, lock, lifeline, location-safe
- patterns: minimal, compass_grid
- shape: shield or circle

Rent a Buddy stamps:
- visual style: helper badge / city guide patch
- icons: handshake, guide flag, language bubble, map, group
- patterns: compass_grid, subtle_map
- shape: rounded_square or luggage_tag

Campaign/official stamps:
- visual style: premium/limited collectible
- icons: star, ribbon, compass, limited mark
- patterns: embossed, foil, passport_paper
- shape: circle or passport_stamp_rectangle

PHASE 4 — Rarity visual system

Apply rarity consistently.

Common:
- simple border
- standard icon
- minimal texture

Uncommon:
- stronger border
- subtle background pattern

Rare:
- double border
- richer background
- small sparkle/highlight

Epic:
- premium border
- subtle animation on detail view
- richer texture

Legendary:
- premium foil/embossed style
- special detail animation
- limited use

Official:
- Travel Buddy official style
- clear “Official” tag
- not government-looking

Limited:
- limited-time ribbon/tag
- campaign dates visible in detail

Build a reusable generated stamp renderer if feasible.

Component:
- StampArtwork

Renderer inputs:
- stamp_type
- category

- shape
- icon_name

- texture
- locked/unlocked state
- size: tiny / small / medium / large / share

Renderer outputs:
- app-rendered stamp artwork
- fallback icon
- accessible label
- locked grayscale version

Rules:
- Use deterministic design from stamp_definition fields.
- Do not rely on remote image loading for every stamp if generated SVG/local rendering can work.

- Stamp must render even if image_url fails.
- Stamp artwork should be cached where safe.

PHASE 6 — Locked vs unlocked stamp artwork

Support locked/unearned stamps if collections/progress display them.

Locked stamp:
- grayscale or muted

- hidden details if secret stamp

Unlocked stamp:
- full color
- earned date
- source summary
- share action if public/allowed

Secret stamp:
- hidden name/details until earned, optional
- generic mystery artwork
- no false hints if criteria are secret
